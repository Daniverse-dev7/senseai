# LinkedIn project update — public launch pending

I’m building SenseAI, a browser-based visual assistant with a Next.js and TypeScript interface.

The project combines TensorFlow.js COCO-SSD integration, Tesseract.js OCR, typed questions grounded in visual evidence, and browser speech controls. Camera-frame processing is designed to run locally in the browser.

My current checkpoint passes five unit tests, seven Chromium browser checks, TypeScript, linting and a production build. Real OCR successfully read text from a generated video frame. Physical-camera testing, actual object-model validation in this restricted environment, and public deployment are still pending.

The engineering focus: useful accessibility controls, clear permission errors, responsible uncertainty, and honest feature status.

Code: https://github.com/Daniverse-dev7/senseai
